# Historial de cambios

## [1.0.0] — 2026-11-26

### Añadido

- Primera publicación como repositorio independiente.
- Aplicación React + TypeScript con mapa de hechos de tránsito 2024, series,
  desgloses por sexo, edad y tipo de persona, y tabla sincronizada con filtros.
- Build portable: la compilación escribe en `app/dist` y no fuera del repositorio.
- Integración continua con `npm ci` y compilación, además de integridad y
  verificación de credenciales.
